Racah Formula

⟨j₁ m₁ j₂ m₂ | J M⟩ = δ(m₁+m₂, M) · √( (2J+1) · Δ(j₁,j₂,J) ) · √( (j₁+m₁)!(j₁−m₁)!(j₂+m₂)!(j₂−m₂)!(J+M)!(J−M)! ) · Σₖ (−1)ᵏ / [ k! (j₁+j₂−J−k)! (j₁−m₁−k)! (j₂+m₂−k)! (J−j₂+m₁+k)! (J−j₁−m₂+k)! ] where Δ(a,b,c) = (a+b−c)!(a−b+c)!(−a+b+c)! / (a+b+c+1)! Sum over k runs where all factorial arguments are ≥ 0.

Symbolic computation powered by Algebrite — a pure JavaScript computer algebra system.

Selection Rules

• m₁ + m₂ = M (projection conservation) • |j₁ − j₂| ≤ J ≤ j₁ + j₂ (triangle inequality) • |m₁| ≤ j₁, |m₂| ≤ j₂, |M| ≤ J • All j and J must be integers or half-integers ≥ 0 • j±m must be non-negative integers (consistency) If any rule is violated, the coefficient is zero.
