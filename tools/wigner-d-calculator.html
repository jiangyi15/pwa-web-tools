Wigner d-Function Formula

djm₁,m₂(β) = Σl=02j wl(j,m₁,m₂) sinl(β/2) cos2j−l(β/2) where the weight wl(j,m₁,m₂) is: wl = (−1)m₁−m₂+k · √((j+m₁)!(j−m₁)!(j+m₂)!(j−m₂)!) / ((j−m₁−k)!(j+m₂−k)!(m₁−m₂+k)!k!) with k = (l + m₂ − m₁)/2, and k ∈ [max(0, m₂−m₁), min(j−m₁, j+m₂)]. Otherwise wl = 0.

Symbolic computation powered by exact BigInt and surd arithmetic — no external CAS dependency.

Properties

• Symmetry: djm₁,m₂(β) = (−1)m₁−m₂ djm₂,m₁(β) • Parity: djm₁,m₂(−β) = djm₂,m₁(β) • Orthogonality: Σm djm,m'(β) djm,m''(β) = δm',m'' • Special case β=0: djm₁,m₂(0) = δm₁,m₂ • Special case β=π: djm₁,m₂(π) = (−1)j−m₁ δm₁,−m₂
