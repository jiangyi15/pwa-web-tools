Angular Projections

The angular distribution I(θ,φ,χ) is expressed as Fourier modes cos(k·θ/2)·cos(k·φ/2)·sin(k·χ/2) etc. All angles use the same half-angle basis with integer k; for half-integer spins the φ/χ k can be odd (giving φ/2, 3φ/2, …). The variable ranges are cos θ ∈ [−1, 1], φ ∈ [−π, π], and χ ∈ [−π, π]. 1D projections are obtained by integrating over all angles except one: \[ I(v) = \int I \prod_{u\neq v} d\mu(u) \] where \(d\mu(\theta_i) = d(\cos\theta_i)\) and \(d\mu(\phi_i) = d\phi_i\), \(d\mu(\chi) = d\chi\). Since the Fourier expansion is a sum of products of single-variable functions, integration reduces each variable independently. The result is a 1D Fourier series in the remaining variable. Normalization: Each projection is normalized to unit integral: \(\int I_{\text{proj}}(v)\,dv = 1\). A uniform distribution then gives marginal density \(I(\cos\theta_i) = 1/2\) (range length 2) and \(I(\phi_i) = I(\chi) = 1/(2\pi)\) (range length \(2\pi\)). This is achieved by dividing the marginal integral \(\int I\prod_{u\neq v} d\mu(u)\) by the total angular integral \(\int I\,d\Omega\).
