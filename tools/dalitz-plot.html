Isobar-Model Formula

For the resonance vertex R → 2 + 3 in a single partial wave (L, S) with a Breit–Wigner propagator, the Dalitz intensity in (s₁₂, s₂₃) is: I(s₁₂, s₂₃) = |BW(m)|² · (q/mR)2L · FL(q·d)² · W(cos θR) where: • s₂₃ = m²23, m = √s₂₃, and q(m) = √λ(s₂₃, m²2, m²3) / (2m) • W(cosθ) = Σλ2,λ3 |√((2L+1)/(2JR+1)) · ⟨J2λ2; J3,−λ3 | S, δ⟩ · ⟨L 0; S δ | JR, δ⟩ · dJRλR,δ(θR)|², δ = λ2−λ3, the φ-integrated θ₁ marginal from the same pipeline as the Angular Projection tool • cosθR = (s₁₂ − m²1 − m²2 − 2E1*E2*)/(2|p1*|q), with E1*, E2*, |p1*| in the 2+3 rest frame — θR measured from the resonance flight direction (tf-pwa helicity convention) • λR = λ1 ranges over the spectator helicities {−J1…+J1} (helicity conservation at a spin-0 parent) • |BW(m)|² = 1 / [(m²R − s₂₃)² + (mR Γ(m))²] with Γ(m) = ΓR (mR/m) (q/qR)2L+1 [FL(q)/FL(qR)]² (mass-dependent) • FL = Blatt–Weisskopf barrier factor (z = q·d) With barrier factors ON the full L-dependent form factor (q/mR)2L·FL(q·d)² is included. With barrier factors OFF there is no L-dependent form factor and no L-dependent width factor — the line shape is a pure Breit-Wigner, independent of the spin/partial wave (only W(cos θR) still carries the J dependence). The parent A → R + 1 enters only through the resonance-helicity set and the phase-space boundary. W(cosθ) is m-independent, so I factorizes into a mass profile times the angular distribution.
